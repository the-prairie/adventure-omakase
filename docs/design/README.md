# Design source

The canonical visual direction is defined in sections 6 and 7 of [`docs/product/adventure-omakase-v1.md`](../product/adventure-omakase-v1.md).

The system is quiet Japanese editorial luxury with tactile travel-journal warmth:

- paper backgrounds and surfaces
- ink typography and strongest actions
- brass for fate and ritual
- vermilion for warnings and rare emphasis
- moss for verified/available states
- restrained borders, radii, texture, motion and haptics

Shared semantic values live in `packages/design-tokens`. Web and native use platform-specific component implementations. The current connectivity screens remain technical status surfaces; they are not approved product-screen completion evidence.
