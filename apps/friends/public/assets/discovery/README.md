# Discovery mood illustrations

`illustrated-moods.webp` is an eight-scene AI-generated illustration atlas, created September 7, 2026 with the built-in image-generation tool for the user's request for more visual discovery. It depicts invented food, architecture, museum, street, forest, coast, running and craft scenes. These are shared thematic illustrations, not photographs, depictions of named venues, or evidence of access or availability.

The original 1774×887 PNG was generated as four columns by two rows. The application selects an illustrated theme from the catalogue mood and subject and labels every preview “Imagined scene · not a venue photo.” The atlas was encoded with `cwebp -q 86`; the shared WebP is approximately 420 KB and is loaded once by the browser. Original catalogue facts, source links and supplied artwork are preserved.

Prompt summary: a regular eight-panel atlas of sophisticated gouache/screenprint Japan travel scenes in forest, cream, rust, ochre and dusty blue, no venue identities or labels. Scenes: noodle counter; concrete museum; natural-history gallery; old backstreet; cedar forest; Okinawa-like cove; riverside runner; ceramics workshop. Output was visually inspected before use.
